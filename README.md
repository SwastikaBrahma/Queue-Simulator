Queue Simulator

Project Overview

The Queue Simulator is a simple C programming mini project that models a ticket counter queue using the basic Queue Data Structure.

It follows the FIFO (First In, First Out) principle, where the person who enters the queue first is served first.

Features

- Add a person to the queue (Enqueue)
- Serve the next person (Dequeue)
- Display people waiting in the queue
- Handle queue overflow and underflow
- Menu-driven interface

Technologies Used

- Programming Language: C
- Data Structure: Queue
- Implementation: Array

How to Run

1. Download the "queue_simulator.c" file.
2. Compile the program using a C compiler.
3. Run the compiled program.

Sample Menu

1. Add Person to Queue
2. Serve Person
3. Display Queue
4. Exit

Objective

The objective of this project is to understand the basic operations of a Queue Data Structure and its practical application in a ticket counter system.
